# Bubble Sort Visualizer

This is a simple Bubble Sort Visualizer made using HTML, CSS and Vanilla JavaScript.

The main aim of this project is to understand how Bubble Sort works by showing every comparison and swap through animation.

## Features

- Generate random array
- Enter your own array
- Array size slider (1 to 100)
- Animation speed control (0.25x to 4x)
- Bubble Sort visualization
- Pause/Resume/Reset button
- Shows array before and after sorting
- Shows total number of swaps
- Supports negative numbers
- Responsive interface

## Color Meaning

- Blue → Unsorted elements
- Yellow → Elements being compared
- Red → Elements being swapped
- Green → Elements that are in their correct position

1. Download or clone the project.

## How to Use

- Click **Generate Random Array** to create a random array.
- Or type your own numbers separated by commas.
- Click **Generate Visualization**.
- Click **Bubble Sort** to start the animation.
- Use **Pause**, **Resume**, and **Reset** whenever needed.

## Bubble Sort

Bubble Sort compares two adjacent elements.

If the left element is greater than the right one, they are swapped.

This process continues until the whole array becomes sorted.

After every pass, one more element reaches its correct position and is shown in green.

## Complexity

Time Complexity

- Best Case : O(n)
- Average Case : O(n²)
- Worst Case : O(n²)

Space Complexity

- O(1)
